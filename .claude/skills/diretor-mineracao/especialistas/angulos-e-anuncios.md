# Especialista — Ângulos e Anúncios

## Ângulo = a porta de entrada da venda
Tipos comuns: dor, desejo, medo, curiosidade, inimigo comum, descoberta/novidade, prova/resultado, identificação ("se você é X…"), contraintuitivo ("pare de fazer Y"), autoridade, história.

## Para cada anúncio de referência
- Link e plataforma; tempo ativo (sinal de que está dando lucro).
- Gancho (primeiros 3 s) transcrito.
- Ângulo e formato (UGC, talking head, slides, depoimento, notícia, POV…).
- Estrutura: gancho → problema → mecanismo → prova → CTA.
- Por que funciona (1 linha).

## Critérios de nota (1–5)
5 = ativo há 30+ dias ou com muitas duplicações, gancho claro, ângulo replicável.
3 = ativo recente, ângulo interessante.
1 = sem sinal de performance.

## Cuidado
Referência é para entender o padrão, nunca para copiar texto ou vídeo de terceiros.

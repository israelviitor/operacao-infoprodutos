# Especialista — Roteiro de Criativo

## Estrutura base (30–60 s)
1. **Gancho** (0–3 s): para a rolagem.
2. **Retenção** (3–8 s): aprofunda a dor/curiosidade, promete a revelação.
3. **Problema + mecanismo do problema**: por que nada funcionou.
4. **Solução + mecanismo da solução**: a virada.
5. **Prova**: resultado, depoimento, autoridade (só o que existe no dossiê).
6. **CTA**: uma ação clara ("clique em saiba mais e assista o vídeo").

## Formato de entrega
| FALA | VISUAL / CENA | TEXTO NA TELA |
|---|---|---|

O texto na tela deve funcionar **sem som** (a maioria assiste mudo).

## Critérios de nota (1–5)
5 = cada frase empurra para a próxima, linguagem falada (frases curtas, ~150 palavras/min), mecanismo claro, CTA único, cabe na duração.
3 = estrutura correta mas frases longas ou genéricas.
1 = parece texto escrito para ler, sem ritmo de fala.

## Regras
- Fale como o avatar fala, não como copywriter.
- Uma ideia por frase. Corte adjetivos.
- Nada de prova inventada: se não há depoimento no dossiê, use outro tipo de prova ou marque [PRECISA DE PROVA].

# Especialista — Ângulos de Criativo

Um lote de teste precisa de **ângulos diferentes**, não de variações do mesmo texto. Cada ângulo testa uma hipótese diferente sobre o que faz o avatar comprar.

## Matriz de ângulos
| Ângulo | Hipótese testada |
|---|---|
| Dor | o público compra para fugir de um sofrimento |
| Desejo | o público compra pelo resultado sonhado |
| Mecanismo/descoberta | o público compra pela novidade da explicação |
| Inimigo comum | o público quer um culpado externo |
| Prova/depoimento | o público precisa ver alguém igual a ele conseguindo |
| Objeção quebrada | algo específico impede a compra (preço, tempo, "não é pra mim") |
| Contraintuitivo | o público está cansado do conselho padrão |

## Regras de escolha
- Priorize ângulos marcados como "pouco explorados" no dossiê.
- Evite os marcados como "saturados", salvo se o dono pedir.
- Em um lote de 5: pelo menos 1 de dor, 1 de mecanismo, 1 de prova (se houver prova real).

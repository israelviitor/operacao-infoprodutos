# Especialista — Operação do Descript (Agent Underlord)

## Como instruir o Underlord
- Instruções **numeradas, uma ação por item**, com critério verificável. Ex.:
  1. Remova palavras de preenchimento (é, ãhn, tipo, né) e silêncios acima de 0,4 s.
  2. Remova as tomadas repetidas, mantendo sempre a última tomada de cada frase.
  3. Reordene para seguir este roteiro: <colar sequência de falas>.
  4. Adicione legendas dinâmicas, 2–4 palavras por vez, centralizadas no terço inferior.
- Divida em etapas: **limpeza** → **estrutura** (ordem, cortes) → **acabamento** (legenda, zoom, b-roll, música, textos).
- Depois de cada etapa, confira a transcrição/composição antes da próxima.
- Sempre informe o formato (9:16 para Reels/TikTok, 1:1 ou 4:5 para feed, 16:9 para VSL desktop).

## Variações
Duplique a composição para cada variação de gancho; nunca sobrescreva a versão aprovada.

## Exportação
- `publish_project` → sempre mostrar ao dono os links de compartilhamento e download.
- Se o dono quiser finalizar em outro editor: `export_timeline` (Premiere XML, DaVinci, FCPXML).
- Legenda separada: `export_transcript` em .srt.

## Aprendizados
Registre aqui (via `registrar-regra` em `regras/edicao.md`) instruções ao Underlord que deram resultado excelente, para reutilizar.
